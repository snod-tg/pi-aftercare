# Agent 实习简历项目描述

## 可直接放入简历

**Pi Aftercare｜服饰电商售后 Agent**　2026.10

**技术栈：** TypeScript、Pi SDK、Tool Calling、BM25、PostgreSQL、React、Fastify、Python、τ-bench

- 基于 Pi SDK 构建服饰电商售后 Agent，封装订单查询、政策检索、规格库存、报价、申请创建及状态查询等 **7 个工具**，实现混合退换货的多轮处理与网页端完整闭环。
- 实现按商家、政策版本和生效时间过滤的 **BM25 政策检索**，返回原文、引用 ID 和检索时间；由业务规则计算退款并校验资格，网页展示可追溯依据及工具执行记录。
- 设计 **宿主确认门禁与稳定幂等键**，在 PostgreSQL 事务内重新校验库存和方案版本；持久化完整 Pi 上下文、工具结果及确认记录，支持刷新、服务重启和提交后响应丢失恢复。
- 构建覆盖未确认提交、越权订单、库存变化、工具异常、响应丢失等 **8 类场景**的故障回归，完成 **24 次 fixture 回归和真实模型网页验收**；适配 τ-bench 原生环境与状态奖励，支持并行评测、断点续跑和失败分析。

三条精简版可将第二条合并进第一条。项目角色、时间和个人贡献应与自己的实际经历一致，不填写不存在的实习或团队经历。

## 30 秒项目介绍

我做的是服饰电商售后 Agent，用户可以一句话提出换码加退货。模型负责选择查询工具和组织方案，宿主负责客户身份、确认和事务约束。网页展示实际政策依据与报价，用户点击确认后才允许创建申请。我重点处理了超时后不知道是否提交成功、重复提交和服务重启丢失上下文的问题，用稳定操作键、状态查询和完整检查点恢复避免盲目重复执行，并通过真实数据库和故障注入验证这些边界。
